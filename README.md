### ✨ Features
- 🔥 Auto lib & plugins supported
- ⚡️ Fast Pair Code - `pair.html`
- 🛡️ Anti-Link, Anti-Badword, Anti-Delete
- 🎮 Fun Plugins - Games, AI, Sticker, Song
- 📥 Auto Downloader - YT, TikTok, Insta, FB
- 👑 Owner & Admin Controls

### 🚀 Deployment Methods

#### 1. Pair Code
Open `pair.html` and get your session.

#### 2. Heroku / Koyeb / Render
- Fork this repo
- Deploy with `app.json`
- Add `SESSION_ID` in env
